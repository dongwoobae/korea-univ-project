# 경사도 편집 도구 바가 기호만 보이는 폭에서 터치 사용자는 버튼 이름을 볼 수 없다

목록·상세 패널이 나란히 서지만 그 사이 틈이 좁은 폭(경계는 `src/app/admin/admin-ui.css`의 `.ku-slope-toolbar` 미디어
쿼리)에서는 편집 도구 바가 글자를 시각적으로만 숨기고 기호(`SlopeEditToolbar`)만 세로로 쌓는다
(`docs/specs/2026-10-14-admin-map-first-redesign-design.md` 6.4). 이름은 접근 이름으로 남고, 마우스를 올리면 `title`로
보인다.

터치에는 마우스 올리기가 없어 `title`이 뜨지 않는다. iPad 가로(1024px)가 이 폭에 든다. 화면을 보는 터치 사용자는
기호만 보고 도구를 골라야 한다. 통째로 옮기기·건물에 붙이기처럼 기호만으로는 뜻을 알기 어려운 도구가 있다.

## 막힌 이유

**차단 사유 없음.** 데스크톱 마우스 사용을 먼저 맞췄고, 태블릿에서 관리자 화면을 쓰는지 확인한 적이 없어 뒤로 미뤘다.

## 트리거

- 관리자가 태블릿으로 경사도를 편집한다는 것이 확인된다
- 이 폭의 도구 바 배치를 다시 손볼 때

## 착수 시 정할 것

- **어떻게 이름을 보일지.**
  - 누르고 있으면(long press) 이름 말풍선 — 짧게 누르면 도구가 바로 실행되므로 실행과 갈라야 한다.
  - 지금 고른 도구의 이름을 도구 바 아래 한 줄로 보이기 — 고르기 전에는 여전히 모른다.
  - 이 폭에서도 글자를 두고 도구 바를 줌 버튼 아래가 아닌 다른 자리(지도 아래쪽 등)에 두기 — 패널과 겹치지 않는
    자리를 다시 찾아야 한다(6.4가 이 폭을 기호 전용으로 정한 이유).
- **포인터 종류로 가를지.** `(hover: none)` 미디어 쿼리로 터치에서만 다른 배치를 쓰면 마우스 사용자의 배치는 그대로다.
