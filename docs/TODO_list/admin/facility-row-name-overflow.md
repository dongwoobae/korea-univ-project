# 긴 시설명이 행 높이를 깨뜨린다

시설 행의 **설명**에는 말줄임 처리가 있는데 **이름**에는 없다
(`src/app/admin/admin-ui.css:1013-1025`).

```css
.ku-facility-row-name {
  display: block;
  font-size: 14px;
  font-weight: 500;
}                      /* overflow 관련 선언 없음 */

.ku-facility-row-desc {
  ...
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

행은 flex이고 본문은 `.ku-facility-row-body { flex: 1 1 auto; min-width: 0 }`,
배지는 `flex-shrink: 0`이다. 그래서 이름이 길면 줄어들 곳이 없어 **이름이
줄바꿈되고 행이 세로로 늘어난다.**

이건 이번 변경의 목적과 직접 부딪힌다. 시설 행을 상세 모달로 바꾼 작업의 검증
항목 중 하나가 "배지 유무로 행 높이가 달라지지 않는다"였고, 수동 검증에서
통과로 판정했다. 그 판정은 **운영 데이터의 이름이 전부 짧았기 때문**이다
(`경사로`, `장애인 화장실`, `본관 엘리베이터`, `지하 1층 엘리베이터`).
배지가 아니라 이름 길이로 깨지는 경로는 그때 밟히지 않았다.

## 막힌 이유

**차단 사유 없음.** CSS 한 블록이고 진행 승인만 남았다.

미룬 이유는 두 가지다. 첫째, 3-lane 리뷰에서 나온 다른 건들(업로드 회귀, 보안)이
먼저였다. 둘째, **어떻게 자를지가 디자인 결정**이라 임의로 정하기 애매했다.

## 트리거

없음. 다만 긴 이름을 가진 시설이 실제로 등록되면 바로 눈에 보인다.
현재 운영 데이터에는 그런 이름이 없어 지금은 드러나지 않는다.

## 착수 시 정할 것

- **한 줄로 자를지, 두 줄까지 허용할지.** 선택지와 함의:
  - **한 줄 + 말줄임**(`-desc`와 동일) — 행 높이가 완전히 고정된다. 대신 긴 이름은
    끝이 잘려 목록에서 구분이 안 될 수 있다. `본관 지하 1층 엘리베이터`와
    `본관 지하 2층 엘리베이터`가 같은 문자열로 보이는 식.
  - **두 줄까지 허용**(`-webkit-line-clamp: 2`) — 구분은 살지만 행 높이가 두
    종류가 된다. "균일한 높이"를 포기하는 것이므로 그게 원래 목표였는지 다시 봐야 한다.
  - **`min-height`로 행을 고정하고 이름은 자름** — 둘을 분리한다. 높이는 확실히
    고정되지만 짧은 행에 여백이 생긴다.
- **모달에서도 잘릴지.** 목록에서 자르면 전체 이름을 어디서 보는지가 남는다.
  시설 상세 모달의 제목은 잘리지 않아야 한다 — 모달 쪽 CSS도 함께 확인할 것.
- **`title` 속성으로 전체 이름을 노출할지.** 잘린 텍스트에 hover 툴팁을 주는
  방법이 있으나, 터치 기기에서는 동작하지 않는다.
