# 이름이 같은 시설을 동영상 선택에서 구분할 수 없다

건물 동영상 섹션의 시설 선택 드롭다운은 **이름만** 보여준다
(`src/components/admin/BuildingVideoManager.tsx:85-87`).

```tsx
<option key={f.id} value={f.id}>
  {f.name ?? f.facility_types?.label}
</option>
```

이름이 없으면 시설 유형 라벨로 떨어지는데, 그러면 `엘리베이터`처럼 유형명이 그대로
option 텍스트가 된다. 한 건물에 엘리베이터가 둘이고 둘 다 이름이 비어 있으면
**목록에 `엘리베이터`가 두 줄 나오고 육안으로 구분할 방법이 없다.**

선택 결과는 id로 처리되므로 잘못 골라도 오류는 나지 않는다. 조용히 **다른 시설의
동영상을 덮어쓴다.** 그 시설에 이미 동영상이 있으면 `기존 동영상이 교체됩니다`
경고가 뜨지만, 그건 "무엇을 고르고 있는지"를 알려주지 않는다.

같은 값으로 판단해야 할 정보가 이미 데이터에 있다 — 층 정보(`floor_info`),
설명(`description`), 시설 유형, 현재 동영상 보유 여부. 드롭다운이 그중 아무것도
쓰지 않는다.

## 막힌 이유

**차단 사유 없음.** 미룬 이유는 우선순위였다.

**실제로 충돌하는 데이터가 있는지 확인하지 않았다.** 운영 DB에서 같은 건물 안에
이름이 겹치는(또는 이름이 비어 유형명으로 떨어지는) 시설이 실제로 있는지부터
세어 볼 것. 없으면 지금은 이론적 문제이고 우선순위가 내려간다.

## 트리거

없음. 아래가 있으면 우선순위가 올라간다.

- 같은 건물에 이름이 겹치는 시설이 실제로 등록된다
- 시설 이름을 비워 두는 운영 방식이 굳는다

## 착수 시 정할 것

- **무엇을 덧붙일지.** 선택지와 함의:
  - **층 정보** — 엘리베이터·화장실처럼 층으로 갈리는 시설에 가장 잘 맞는다.
    대신 `floor_info`가 비어 있는 행이 많으면 도움이 안 된다. 착수 전에 채워진
    비율을 확인할 것.
  - **시설 유형 라벨을 항상 앞에 붙인다** (`[엘리베이터] 본관 승강기`) — 규칙이
    단순하고 항상 값이 있다. 대신 이름이 이미 유형을 담고 있으면 중복돼 보인다.
  - **동영상 보유 표시**(`· 동영상 있음`) — 교체인지 신규인지 고르기 **전에**
    보인다. 지금은 고른 뒤에야 경고가 뜬다. 구분 문제와는 다른 축이라 함께 넣어도 된다.
- **드롭다운을 유지할지.** option은 텍스트만 담을 수 있어 정보를 겹쳐 넣으면
  금세 길어지고, 좁은 화면 폭 문제와도 얽힌다(같은 폴더의
  `video-picker-narrow-width.md`). 시설 목록에서 직접 고르는 방식(행 클릭)으로
  바꾸면 배지와 층 정보를 그대로 쓸 수 있다. 다만 그건 이 섹션의 UI를 다시
  설계하는 일이라 범위가 커진다.
- **근본 쪽을 건드릴지.** 같은 건물 안 시설명 중복을 입력 단계에서 막거나
  경고하는 방법도 있다. 그러면 선택 UI는 지금 그대로 둘 수 있다. 대신 기존
  데이터에 이미 중복이 있으면 그것부터 정리해야 한다.
