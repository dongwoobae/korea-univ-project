# 좁은 화면에서 동영상 시설 선택 행이 카드를 넘칠 수 있다

건물 동영상 섹션의 시설 선택 UI는 `select` + `확인` + `취소`를 줄바꿈 없는
flex 한 줄에 둔다 (`src/components/admin/BuildingVideoManager.tsx:77`).

```tsx
<div style={{ display: "flex", gap: 8, paddingTop: 12 }}>
```

`flexWrap`이 없고 `select`에도 `minWidth: 0`이나 가변 폭 지정이 없다. `select`의
고유 폭은 **가장 긴 option 텍스트**를 따라가므로, 시설명이 길면 세 컨트롤의 최소
너비 합이 390px 카드 안쪽 폭을 넘을 수 있다.

수동 검증에서는 이 경로가 밟히지 않았다. 확인한 건물의 시설명이
`본관 엘리베이터` 정도라 세 컨트롤이 한 줄에 들어갔다. 관련 E2E도 데스크톱 폭에서만
돈다.

**수정 자체는 한 단어에 가깝다** — 컨테이너에 `flexWrap: "wrap"`을 주고
`select`에 `minWidth: 0`을 더하면 넘칠 때 줄바꿈된다. 지금 안 넣은 이유는 리뷰
결과를 "수정 / 후속 / 반려"로 나눌 때 이 건을 후속으로 분류했고, 분류를 정한 뒤
말없이 범위를 넓히지 않기로 했기 때문이다.

## 막힌 이유

**차단 사유 없음.** 분류상 뒤로 미룬 것뿐이다.

**실제로 넘치는 것을 보지는 못했다.** 위 서술은 코드와 CSS를 읽고 세운 것이다.
착수하면 긴 이름을 가진 시설을 만들어 390px에서 재현하는 것부터 할 것 —
재현이 안 되면 고칠 필요가 없다.

## 트리거

없음.

## 착수 시 정할 것

- **줄바꿈으로 갈지, select를 줄일지.**
  - **`flexWrap: "wrap"`** — 넘치면 버튼이 아랫줄로 내려간다. 가장 단순하고
    어떤 이름 길이에도 안전하다. 대신 줄이 두 개가 되면서 카드 높이가 변한다.
  - **`select`에 `flex: 1 1 auto; min-width: 0`** — 한 줄을 유지하고 select가
    줄어든다. 대신 선택된 시설명이 잘려 보인다.
  - 둘 다 — 우선 줄이고, 그래도 모자라면 줄바꿈.
- **인라인 스타일로 둘지 클래스로 뺄지.** 이 컴포넌트는 인라인 스타일을 쓰고
  있으나, 같은 리뷰에서 `FacilityDetailModal`의 액션 영역이 인라인으로 스타일을
  재현하다 모바일 sticky·터치 높이 규칙을 놓친 사례가 나왔다(`bb6a564`에서 수정).
  반응형이 걸리는 요소는 클래스로 빼는 편이 안전하다.
- **E2E에 좁은 폭 케이스를 넣을지.** 지금 스위트는 데스크톱 폭만 돈다. 넣는다면
  이 컴포넌트만을 위해 뷰포트를 바꾸는 테스트를 추가할지, 모바일 폭 전용 스펙을
  따로 만들지 정해야 한다.
