# 공개 지도 메뉴 재배치(PR ④) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 공개 지도의 검색·필터·즐겨찾기·목록을 웹에서는 접을 수 있는 왼쪽 아이콘 줄로, 모바일에서는 아래 가로 줄로 옮긴다.

**Architecture:** 열린 패널 하나(`openPanel`)와 접힘 여부를 `Map`이 `useMapMenu` 훅으로 든다. 화면 모드는 `expanded`(지금 모습 +
접기)·`rail`(접힌 줄)·`bar`(모바일) 셋이고, 패널 내용 구성 요소(검색·필터·즐겨찾기·목록)는 세 모드가 같이 쓴다. 메뉴 UI는 모두
Leaflet 컨테이너 밖에 둔다.

**Tech Stack:** Next 16.2.4, React 19.2.4(React Compiler), react-leaflet 5, Leaflet 1.9.4, lucide-react 1.31.0, vitest(node 환경),
Playwright(목 백엔드 `e2e/support/mockBackend.ts`).

**Spec:** `docs/specs/2026-10-27-map-menu-design.md`(세부), `docs/specs/2026-10-25-mentoring-feedback-design.md` 6장(요구·사용자 결정).

## Global Constraints

- 저장 키 `ku_menu_collapsed`, 값 `"true"`/`"false"`, 없거나 모르는 값·예외는 펼침(멘토링 설계 2장).
- 폭 경계 768px(`window.innerWidth < 768`이 모바일). CSS는 지금처럼 `@media (max-width: 767px)`.
- 터치 대상 44px 이상(접힌 줄·아래 줄과 그 패널 안).
- 문구는 세 언어(ko·en·zh) 모두. 커밋·주석·문서에 날짜만 적고 과정 이름을 적지 않는다. `Co-Authored-By` 없음.
- 로컬에서 npm ci·vitest·tsc·eslint·Playwright를 돌리지 않는다 — PR CI로 본다. `gh workflow run` 금지.

  - `toggle(panel)` — 닫혀 있으면 `flushSync`로 열고 첫 조작에 초점, 열려 있으면 닫기
  - `closeAndRestoreFocus()` — 닫고 연 버튼에 초점(Esc·닫기 버튼·항목 고르기)
  - `dismiss` — 안정 참조. 닫기만(지도 누르기·건물 선택·펼침 검색 활성)
  - `setCollapsed(next: boolean)` — 저장, 패널 닫기, 짝 버튼에 초점
  - `handleBreakpoint(apply: () => void)` — 안정 참조. `flushSync`로 `apply()`와 닫기를 같이 그리고, 초점이 패널 안이었으면 새 모드의
    여는 자리로
  - `triggerRefs: Record<MenuPanel, (el: HTMLElement | null) => void>`, `collapseButtonRef`, `expandButtonRef`
  - 패널이 열려 있는 동안 `window` `keydown`(Esc, `defaultPrevented`면 건너뜀)
- `MapMenuNav({ orientation: "rail" | "bar", openPanel, counts: Partial<Record<MenuPanel, number>>, onToggle(panel), triggerRefs,
onExpand?, expandButtonRef? })`

  `--ku-visible-top`·`--ku-visible-bottom`을 맞춘다.

  뿌리 id `MENU_PANEL_ID.search`. `useMap` 없음. 흐림 타이머·음성 인식은 사라질 때 정리.
