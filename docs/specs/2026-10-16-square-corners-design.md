# 각진 모서리

2026-10-16

공개 지도와 관리자 화면의 모달·패널·카드·버튼·입력을 직각으로 바꾼다. 둥근 모서리가 주는 가벼운 인상 대신
기관 서비스다운 단단한 인상을 주려는 것이다.

## 규칙

1. 반경은 `globals.css`의 `--ku-radius` 하나로 정하고, 값은 `0`이다. 모서리가 있는 상자는 모두 이 토큰을 쓴다.
   새 컴포넌트도 CSS·인라인 스타일·마커 HTML에 숫자 반경을 쓰지 않는다.
2. `50%`로 그린 원은 그대로 둔다. 지도 마커·클러스터, 현재 위치 점, 상태 점, 번호 원, 원형 닫기 버튼 같은 것이다.
   원은 모서리가 아니라 그 요소의 모양이다. 시설 마커의 핀 모양(`50% 50% 50% 4px`)도 마커 모양이라 그대로다.
3. 알약 모양(`999px`의 칩·배지·세그먼트, 개수 배지)과 작은 막대(경사 프로파일, 시트 손잡이, 진행 막대)는 직각이다.
   사진 넘김 표시의 점도 정사각형이 된다. 활성 표시가 막대라서 점만 원으로 두면 한 줄 안에서 모양이 갈린다.
4. 한쪽만 둥글던 곳(모바일 시트의 위쪽 두 모서리, 경사 구간 표 머리의 양 끝)은 그 모서리 자리에 토큰을 둔다.
   토큰 값을 키우면 원래 둥글던 모서리만 둥글어진다.
5. 이미 `0`이던 곳(모바일에서 화면을 채우는 상세 패널·등록 요청 모달, 지도 확대 버튼 묶음 안쪽 버튼)은 토큰과
   상관없이 `0`으로 둔다. 화면 가장자리나 이웃 버튼에 붙는 면이라 토큰을 키워도 직각이어야 한다.
6. Leaflet·geoman이 기본으로 주는 반경(확대 버튼 묶음·팝업·툴팁·그리기 툴바 등)은 `globals.css`에서
   `!important`로 토큰에 맞춘다. 두 CSS는 `globals.css`보다 늦게 불리고, 툴바 첫·끝 버튼 규칙은 특이도가 더 높다.
   그래서 Leaflet 툴팁에 붙는 클래스(`.ku-building-label`, `.ku-workspace-marker-tooltip` 등)는 반경을 따로 정해도
   이 규칙에 진다.

## 관리자 리디자인 핸드오버와의 관계

핸드오버(`2026-10-14-admin-map-first-handoff/README.md`)의 반경 값(8·10·14·999 등)은 따르지 않는다. 핸드오버
원문은 받은 그대로 둔다. 리디자인 설계는 2.13에서 이 문서를 가리킨다.

## 범위 밖

`src/app/page.module.css`는 어디서도 불러오지 않는 파일이라 고치지 않았다.

## 테스트

`e2e/admin-shell.spec.ts`의 건물 카드 버튼 반경 단언이 `8px`에서 `0px`로 바뀐다. 다른 테스트는 반경을 보지 않는다.
