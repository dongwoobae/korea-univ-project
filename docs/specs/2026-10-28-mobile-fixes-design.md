## 1. 좁은 화면 기준과 가로 모드

### 1.1 기준

- 지금 모바일 레이아웃은 폭 767px 이하다. CSS는 `map-ui.css`의 `@media (max-width: 767px)` 두 블록이고, JS는 `Map.tsx`와
  `SidePanel.tsx`가 각자 `window.innerWidth < 768`을 본다.
- 휴대폰을 가로로 들면 폭이 768px을 넘는 기기가 많다(844×390, 852×393, 932×430). 이 화면들은 웹 레이아웃이 된다. 그래서 MOB-08
  (확대 버튼이 언어 상자 밑)과 MOB-14(접힌 줄이 출처 표기를 덮음)가 생겼다.
- 경사도 버튼(2장)이 열에 더해지면 웹 펼친 모습의 열이 더 길어진다. 844×390에서는 확대 묶음을 빼도 열 위 끝이 언어 상자에 닿는다
  (열 358px + 아래 20px, 위 끝 y12).
- **[판단]** 좁은 화면을 "폭 767px 이하 **또는** 가로이면서 높이 500px 이하"로 넓힌다. 휴대폰 가로는 폭과 상관없이 아래 줄
  레이아웃이 된다. 높이 500px 이하로 줄인 데스크톱 창도 같은 대접을 받는다. 터치에 맞춘 배치라 쓰는 데 문제는 없다.
  - CSS: 두 블록의 조건을 `@media (max-width: 767px), (orientation: landscape) and (max-height: 500px)`로 바꾼다.
  - JS: 같은 조건 문자열 하나(`COMPACT_MEDIA_QUERY`)를 `src/lib`에 두고 `window.matchMedia(...).matches`로 읽는다. `Map.tsx`·
    `SidePanel.tsx`의 `innerWidth < 768` 네 곳을 바꾼다. CSS는 이 문자열을 가져올 수 없으므로 두 블록 위 주석이 그 이름을 가리킨다.
  - `PhotoCarousel`의 이미지 `sizes` 힌트(`max-width: 767px`)는 그대로 둔다. 레이아웃이 아니라 받을 이미지 크기 힌트다.
- PR #66이 더한 낮은 웹 화면의 확대 묶음 숨김(`min-width: 768px and max-height: 470px`)은 이 기준으로 해당 화면이 모두 좁은 화면이
  되어 쓰이지 않는다. 대신 경사도 버튼이 더해진 웹 펼친 모습은 높이 약 542px 미만에서 확대 버튼이 언어 상자에 닿는다(열 476px
  포함 아래 여백). 조건을 `max-height: 560px`로 올린다.

### 1.2 가로 좁은 화면 배치 (`(orientation: landscape) and (max-height: 500px)`이면서 좁은 화면)

- **상세(`.ku-side-panel`)** **[사용자]** 아래 시트 대신 오른쪽 옆 패널이다. 폭은 `min(360px, 50vw)`, 높이는 화면 전체다. 오른쪽에서
  밀려 나오고, 손잡이(`.ku-side-handle`)와 세로로 끌어 닫기는 없다. 닫기는 제목 줄의 ×다. 아래 줄과 지도 버튼 열은 지금 모바일처럼
  상세가 열린 동안 숨는다.
  - `SidePanel.tsx`의 끌어 닫기는 세로 좁은 화면에서만 켠다.
  - **[판단]** 언어 상자는 상세가 열리면 웹처럼 옆 패널 왼쪽으로 비킨다. 옆 패널이 언어 상자 위에 쌓여, 그대로 두면 상세가 열린
    동안 언어를 바꿀 수 없다.
- **지도 버튼 열** 오른쪽 아래에 가로 한 줄로 눕힌다. 왼쪽부터 `가−`·`가＋` 줄, 현 위치, 위성, 경사도, 피드백이다. 아래 줄 위
  12px이다. 줄 폭은 334px이다(`가−`·`가＋` 줄 48×2 + 간격 6, 버튼 48×4, 간격 10×4). 확대 묶음은 좁은 화면에서 숨고, 다크모드
  토글은 웹 펼침에만 있다.
  - 그래서 오른쪽 위 언어 버튼과 부딪히지 않는다(⑥ 설계 1.2가 ⑦로 넘긴 한계).
- **경사도 범례** **[판단]** 버튼 줄 바로 위(10px)에 버튼 줄과 같은 폭으로 둔다. 버튼 줄 왼쪽에 두면 범례 폭이 화면 폭을 따라
  줄어 568 폭에서 192px가 된다(667 폭은 291px). 눈금 숫자는 고정이라(⑥ 설계 2.2) 240px보다 좁으면 이웃 눈금이 겹친다
  (`slope-bands-legend.css`의 폭 주석).
  - 범례와 버튼 줄을 한 상자(`.ku-map-corner`)에 세로로 쌓는다. 범례 폭이 버튼 수를 세지 않고 줄의 실제 폭을 따른다.
- **출처 표기** 왼쪽 아래 그대로다. 667 폭에서 버튼 줄과 떨어진다. 568 폭(1세대 iPhone SE 가로)에서는 겹친다 — 받아들인다.

## 2. 경사도 켜기를 지도 버튼으로 **[사용자]**

- 2026-10-28 팀 의견을 사용자가 받아들였다. 경사도는 시설을 거르는 것이 아니라 지도 위에 겹치는 층이라 위성(바탕 지도)과 같은
  묶음이다. 휠체어 이용자에게는 필터 열기 → 체크 → 닫기 대신 한 번에 닿는다.
- 필터 패널의 경사도 체크(`FilterPanel.tsx`)를 지운다. 명소 체크는 그대로다. 필터 배지 숫자(`activeFilterCount`)에서 경사도를 뺀다.
- 지도 버튼 열에서 위성 다음에 둔다. 모양은 위성과 같은 `ku-map-action ku-map-action--labeled`, 아이콘 `Mountain`, 이름
  `t("slopeToggle")`(경사도·Slope·坡度)이다. 모바일은 다른 열 버튼처럼 아이콘만 보인다.
  - 2026-10-29 아이콘을 밑선 없는 꺾은선(`SlopeLineIcon`)으로 바꾸고, 모바일에서도 이름을 보인다
    (`docs/specs/2026-10-29-map-buttons-feedback-design.md` 1·2장).
  - 이름은 켜고 꺼도 바뀌지 않는다. 켜짐은 `aria-pressed`와 색(언어 버튼의 선택과 같은 크림슨 바탕)으로 보인다. 위성 버튼은 이름이
    바뀌는 방식이라 다르다.
- 열 차례
  - 웹 펼침: 확대·축소 → 현 위치 → 위성 → **경사도** → 다크모드 → 글자 크기 → 피드백
  - 웹 접힌 줄: 확대·축소 → 현 위치 → 위성 → **경사도** → 글자 크기 → 피드백
  - 세로 좁은 화면: 글자 크기 → 현 위치 → 위성 → **경사도** → 피드백(위에서 아래)
  - 가로 좁은 화면: 1.2

## 3. 고른 건물이 상세에 가리지 않게 (MOB-09)

- 검색(`handleSearchBuilding`)과 즐겨찾기(`handleSelectById`)의 `fitBounds`에 상세가 덮을 자리를 여백으로 준다.
  - 세로 좁은 화면: `paddingBottomRight: [0, 시트 높이]`. 시트 높이는 `mobileSheetHeight(innerHeight)`(`buildingLabel.ts`)다.
  - 가로 좁은 화면: `[옆 패널 폭, 0]`.
  - 웹: `[340, 0]`(웹 상세 패널 폭). 웹은 건물이 가운데에 와 대개 보이지만 큰 건물은 오른쪽이 패널에 들어갔다.
  - 여백 값은 한 함수가 화면 종류에 따라 돌려준다. CSS의 패널 폭·시트 높이와 같은 식이어야 하므로 그 함수 주석이 CSS 규칙을 가리킨다.
- 지도를 눌러 고른 건물의 이름 드러내기(멘토링 설계 5.2, `revealLabelAboveSheet`)는 세로 좁은 화면에서만 쓴다. 가로 좁은 화면에서는
  이름이 옆 패널 밑이면 같은 셈을 가로로 해서 지도를 왼쪽으로 옮긴다. **[판단]**

## 4. 작은 것들

### 4.1 검색 결과 수 (MOB-10)

- 좁은 화면 검색 패널은 바탕이 투명하고 결과 목록만 흰 상자다. 결과 수(`.ku-search-count`)와 "결과가 많다" 안내(`.ku-search-note`)를
  결과 상자와 같은 바탕·테두리로 목록 바로 아래에 붙인다. 내용이 없으면(`:empty`) 그리지 않는다.
- 두 글자색은 웹을 포함한 모든 배치에서 `--ku-text-3` 대신 `--ku-text-2`로 한다. `--ku-text-3`은 흰 바탕에서 3.73:1이라 바탕만
  바꿔서는 4.5:1에 닿지 않는다.
- 결과 수의 `role="status"`·`aria-live`는 그대로다.

### 4.2 검색창 기본 지우기 (MOB-11)

- `.ku-search-input::-webkit-search-cancel-button`을 감춘다(`-webkit-appearance: none; appearance: none`). 앱의 지우기 버튼
  (`.ku-search-clear`)이 같은 일을 한다. 입력 종류(`type="search"`)는 휴대폰 키보드의 "검색" 키 때문에 그대로 둔다.

### 4.3 등록 요청 닫기 (MOB-12)

- 제목과 ×를 `.ku-request-modal-header`로 묶는다. ×는 피드백 모달의 `.ku-feedback-close`와 같은 모양·크기이고, 이름은
  `t("closeLabel")`이다. 보내는 중에는 피드백처럼 누를 수 없다. 아래 "닫기" 버튼은 그대로다.

### 4.4 다크 로고 (MOB-13)

- 다크에서 `.ku-attribution img`에 밝은 판을 깐다(흰 바탕, `--ku-radius`, 안쪽 여백 2px 4px). 로고 그림은 그대로다.

### 4.5 접힌 줄과 출처 표기 (MOB-14)

- 겹치던 화면(웹 레이아웃, 높이 약 479px 미만)은 가로이면서 높이 500px 이하라 1장 기준으로 모두 좁은 화면이 된다. 따로 고치지
  않고 시험으로 확인한다.

### 4.6 영어 목록 (MOB-16)

- 목록 이름(`.ku-map-browse-copy strong`)을 한 줄 말줄임 대신 두 줄까지 보인다(`-webkit-line-clamp: 2`). 세 줄째부터 말줄임이다.
- 영어 이름이 빈 명소는 데이터다. PR 본문에 목록을 적고 사용자가 관리자 화면에서 채운다.

## 5. 터치 대상 24×24 (MOB-05) **[사용자]**

- 사진 넘김 점(`PhotoCarousel.tsx`): 버튼을 24×24 투명 상자로 키우고, 보이는 점(6×6, 현재 사진은 16×6)은 그 안의 가상 요소로
  그린다. 인라인 스타일을 CSS 클래스로 옮긴다. 버튼 이름 `n번째 사진`은 한국어로 박혀 있어 이참에 번역 키로 바꾼다. **[판단]**
- 경사도 범례 칸(`.ku-slope-bands-cell`): 높이 20px → 24px. 보이는 막대 8px는 그대로이고 칸 가운데에 둔다.
- 시트 손잡이(`.ku-side-handle`): 높이 22px → 24px 이상(위아래 안쪽 여백).
- Leaflet 팝업 닫기(24×24)는 이미 맞고, 출처 링크는 글 속 링크라 WCAG 2.5.8의 예외다.

## 6. safe-area (MOB-06) **[사용자]**

- `viewport-fit=cover`를 켜지 않으므로 `env(safe-area-inset-bottom)`은 늘 0이다. 그 호출을 지운다 — `calc(X + env(...))`는
  `X`로, `padding-bottom: env(...)`처럼 그것만 있는 선언은 선언째 지운다. 대상은 `admin-ui.css`와 `map-ui.css`다.
- 화면은 바뀌지 않는다.

## 7. 시험

### 7.1 새 E2E

- 가로 좁은 화면(740×360, 844×390): 아래 줄이 있고 접힌 줄이 없다. 지도 버튼 열이 가로 한 줄이고 버튼 위 끝이 모두 언어 버튼 아래
  끝보다 아래다. 상세를 열면 오른쪽 옆 패널(오른쪽 끝이 화면 오른쪽, 높이가 화면 전체)이고 손잡이가 없다. 범례가 버튼 줄 위에
  있어 겹치지 않고, 667×375에서 눈금끼리 겹치지 않는다.
- 웹(1280×800)·세로 좁은 화면(390×844)은 지금 레이아웃 그대로다.
- 경사도 버튼: 세 모드에서 위성 다음에 있다. 누르면 `aria-pressed="true"`, 경사도 선이 그려지고 범례가 보인다. 다시 누르면 사라진다.
  필터 패널에는 경사도 체크가 없고, 경사도를 켜도 필터 배지가 늘지 않는다.
- MOB-09: 세로 좁은 화면(360·390·430)에서 검색·즐겨찾기로 고르면 선택된 이름 가운데가 시트 위 끝보다 위다. 가로 좁은 화면에서는
  옆 패널 왼쪽 끝보다 왼쪽이다. 웹에서는 상세 패널 왼쪽 끝보다 왼쪽이다.
- MOB-10: 390 검색 결과 수 글자의 대비가 4.5:1 이상이다(바탕이 결과 상자).
- MOB-11: 검색창의 기본 지우기 버튼이 보이지 않는다(가상 요소의 `appearance`/표시를 잰다).
- MOB-12: 등록 요청 모달 위쪽 ×로 닫힌다. 키보드로도 닿는다.
- MOB-13: 다크에서 로고 뒤 바탕이 밝다(로고 상자의 배경색).
- MOB-14: 844×390·932×430에서 접힌 줄이 없다(1장).
- MOB-16: 영어 360 크게 목록 이름이 두 줄까지 보인다(한 줄 높이보다 크고 세 줄 높이보다 작다).
- MOB-05: 사진 넘김 점·범례 칸·손잡이가 24×24 이상이다.

### 7.2 고치는 기존 E2E
