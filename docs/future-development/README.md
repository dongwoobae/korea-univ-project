# 후속 개발 문서

현재 릴리스 범위를 넘어서는 대규모 기능과 구조 변경을 기록한다.
각 문서는 현재 구현의 단순한 미완료 항목이 아니라, 별도의 설계·데이터 구축·사용자
검증이 필요한 후속 개발 과제로 취급한다.

## 문서 목록

- [접근 가능한 경로 탐색](./accessible-routing.md)
  - 캠퍼스 보행로 네트워크
  - 보행로에 종속된 경사도 데이터
  - 계단·엘리베이터·공사 및 통행 제한을 반영한 경로 탐색

## 운영 원칙

- 현재 지도 완성에 필요한 UX·접근성 개선과 후속 고도화 범위를 분리한다.
- 후속 기능을 위해 현재 데이터 모델을 성급하게 확장하지 않는다.
- 구현을 시작하기 전에 실제 캠퍼스 조사 범위와 데이터 관리 주체를 확정한다.
- 경로 탐색처럼 안전에 영향을 주는 기능은 실제 사용자와 현장 검증을 완료한 뒤
  대표 기능으로 노출한다.
